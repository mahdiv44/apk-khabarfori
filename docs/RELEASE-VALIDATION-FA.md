# گزارش بررسی نسخه ۲۰۲۶-۱۰-۱۱

## اجراشده و موفق

- نصب وابستگی‌ها از lockfile و به‌روزرسانی lockfile برای کتابخانه‌های WebAuthn.
- `backend: npm run build`: تولید Prisma Client و کامپایل TypeScript موفق.
- `backend: npm test`: ۳۷ آزمون، ۳۷ موفق، صفر ناموفق.
- آزمون‌ها شامل مجوزهای نقش، ابطال نشست، خبر ویژه، محرمانگی پیش‌نویس، جعل MIME، callback پرداخت، CSRF و کوکی امن، مرتب‌سازی تلگرام، جلوگیری از آدرس داخلی در خوراک سایت، توکن حقوق وابسته به حساب/نسخه/انقضا، حذف توکن حقوق از JSON مرورگر و منع اتکا به ایمیل تأییدنشده هستند.
- ساخت تولیدی Next.js پنل با webpack موفق شد: صفحات `/` و `/mobile` و پراکسی `/api/platform/[...path]` تولید شدند. محیط بررسی آمار RSS حافظه را در اختیار Node نمی‌گذاشت؛ یک shim موقت فقط برای اندازه‌گیری حافظهٔ ابزار build استفاده شد. این shim داخل محصول یا بسته تحویل نیست.
- پس از اصلاح نهایی اعلان و وضعیت اولیه داشبورد، بررسی TypeScript پنل مجدداً موفق شد.
- هر سه migration SQL از دیتابیس خالی روی موتور PostgreSQL سازگار PGlite اجرا شد. جدول‌های حقوق/جلسات/کلید دستگاه ایجاد شدند؛ انتخاب جلسهٔ موعدرسیده و حذف آن از صف پس از ثبت یادآوری آزمایش شد.
- بررسی syntax اسکریپت‌های Bash و کامپایل فایل‌های Python موفق بود.

## اجرا نشده / نیازمند محیط مقصد

- اتصال SSH سرور: خطای `Network is unreachable` پیش از handshake. هیچ استقرار یا migration روی VPS انجام نشده است.
- آزمون API یکپارچه با سرویس مستقل PostgreSQL و NestJS در این محیط اجرا نشد. سناریوهای HTTP حقوق و جلسات به `backend/test/integration.mjs` اضافه شده‌اند و برای CI/سرور آماده‌اند، اما اجرای جدید آن‌ها تأیید نشده است.
- اجرای تعاملی پنل در مرورگر، صحت نمایش روی گوشی، WebAuthn با سخت‌افزار واقعی و دریافت FCM تأیید نشده‌اند. محدودیت سیستم و شبکهٔ محیط مانع smoke test سرویس محلی شد.
- Flutter/Android SDK موجود نبود؛ تحلیل Flutter، تست موبایل و تولید APK اجرا نشده‌اند.
- collector سایت و نشست تلگرام روی منابع زنده، تنظیم دامنه/TLS، کلیدهای Firebase، بازیابی backup، کارایی تحت بار و سازگاری با دیتابیس احتمالی فعلی سرور باید در مقصد بررسی شوند.
- رتبه‌بندی سایت فاقد آمار واقعی با برچسب «نامشخص» نمایش داده می‌شود؛ RSS لزوماً آمار بازدید منتشر نمی‌کند.
- اثرانگشت در وب‌اپ از WebAuthn استفاده می‌کند؛ دستگاه می‌تواند PIN یا چهره را نیز برای تأیید کاربر انتخاب کند. نسخه Flutter این مسیر را در مرورگر امن باز می‌کند، نه احراز اثرانگشت بومی داخل Flutter.

## تغییرات مهم امنیتی و عملیاتی

فیش حقوق با نشست عادی قابل خواندن نیست. مجوز حقوق پنج دقیقه اعتبار دارد؛ تغییر رمز حقوق/حساب متصل و ابطال نشست مانع استفاده از مجوز قبلی می‌شود. برای خواندن فیش، کارمند باید فعال باشد. داده فیش در تغییر زبانه یا رفتن اپ به پس‌زمینه پنهان می‌شود. API پاسخ‌ها را `no-store` می‌کند.

واردات خبر بدون نویسنده مجاز انجام نمی‌شود؛ پیش‌فرض REVIEW است. لینک منبع یکتا، بازدید منبع مستقل از بازدید داخلی و آمار ناموجود null است. زمان‌بند هم‌پوشانی داخل پردازش را محدود می‌کند؛ یکتایی دیتابیس مانع ثبت چندباره همان URL است.

یادآوری جلسه و علامت انجام آن در یک تراکنش نوشته می‌شود. ارسال FCM صف و retry دارد؛ تحویل دقیقاً یک بار تضمین نمی‌شود. بدون Firebase فقط اعلان درون‌برنامه‌ای موجود است. جزئیات حساس داخل متن push صفحه قفل قرار نمی‌گیرد.

کلید SSH، رمز سرور، نشست تلگرام، کلید Firebase و فایل تنظیمات واقعی در ZIP وجود ندارد. پوشه‌های وابستگی و خروجی build نیز عمداً در بسته سورس نیستند.
