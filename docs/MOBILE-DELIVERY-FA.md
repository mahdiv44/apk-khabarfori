# خبرفوری: اندروید نصب‌شونده و وب‌اپ آیفون

خروجی‌های هدف پروژه بر اساس درخواست جدید:

| دستگاه | خروجی |
|---|---|
| اندروید | فایل APK از اپ Flutter |
| آیفون و آیپد | وب‌اپ در مسیر `/mobile` |
| مدیران سازمان | پنل مدیریت وب در مسیر `/` |

## استفاده در آیفون

مسیر `/mobile` را در Safari باز کنید. از Share، گزینه Add to Home Screen را انتخاب کنید؛ اگر Open as Web App نمایش داده شد، آن را روشن کنید و Add را بزنید. راهنما با دکمه تلفن در بالای وب‌اپ نیز در دسترس است. [راهنمای رسمی اپل](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios).

وب‌اپ صفحه اصلی خبری، جست‌وجو، اشتراک ویژه، ذخیره خبر، پروفایل، همکاران و ارتباط با سردبیر دارد. ظاهر دارای نوار پایین و فضای امن نمایشگر آیفون است. صفحه اصلی و آیکن برنامه در manifest تعریف شده‌اند.

برای استفاده آنلاین به اینترنت نیاز است. service worker فقط صفحه عمومی «اتصال اینترنت» را ذخیره می‌کند؛ داده حساب، متن‌های VIP، اطلاعات کارکنان و پاسخ API آفلاین ذخیره نمی‌شوند. اعلان push برای وب‌اپ iOS در این تغییر پیاده‌سازی نشده است. لینک پیش‌نمایش همچنان خصوصی و داده‌های آن نمونه‌اند.

## ساخت APK اندروید

**فایل APK هنوز ساخته نشده است.** در محیط فعلی Flutter SDK و Android SDK وجود ندارد. فایل سورس ZIP، فایل قابل نصب اندروید نیست.

مسیر آماده برای ساخت ابری:

1. کد را در یک مخزن GitHub با Actions فعال قرار دهید.
2. از بخش Actions، گردش کار `Build installable KhabarFori Android APK` را اجرا کنید.
3. `api_url` را نشانی واقعی و فعال NestJS همراه با `/api/v1` وارد کنید.
4. `web_url` را مبدا HTTPS وب‌سایت وارد کنید.
5. برای نصب آزمایشی، `review` را انتخاب کنید. خروجی با کلید debug امضا می‌شود و برای انتشار عمومی نیست.
6. بعد از موفقیت کامل ساخت، فایل APK را از بخش Artifacts همان اجرا دریافت کنید.

گردش کار قبل از ساخت، سلامت API را بررسی می‌کند و برنامه‌ای با نشانی سرور خاموش یا نشانی پیش‌نمایش به‌جای API تولید نمی‌کند. سپس وابستگی‌ها را دریافت می‌کند، تحلیل و آزمون‌های Flutter را اجرا می‌کند و APK می‌سازد. این گردش کار در این گفتگو هنوز اجرا نشده است.

برای انتشار نهایی، حالت `release` را انتخاب کرده و secrets زیر را در مخزن تنظیم کنید؛ کلید خصوصی را در گفتگو یا Git قرار ندهید:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_STORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

اسکریپت انتشار در نبود کلید معتبر متوقف می‌شود و به امضای debug برنمی‌گردد. تغییر کلید امضا می‌تواند مانع نصب به‌روزرسانی روی نسخه قبلی شود؛ کلید انتشار را امن و پایدار نگه دارید. [راهنمای رسمی Flutter برای ساخت اندروید](https://docs.flutter.dev/deployment/android).

ساخت محلی نیز با Flutter و Android SDK ممکن است: متغیرهای `API_URL`، `PUBLIC_WEB_URL` و `BUILD_MODE` را تنظیم و از ریشه پروژه `bash mobile/build-apk.sh` را اجرا کنید.

## وضعیت تحویل

- وب‌اپ موبایل و تنظیمات افزودن به Home Screen پیاده‌سازی شده است.
- سورس Flutter و گردش کار تولید APK آماده است.
- APK، امضای انتشار و آزمون واقعی روی آیفون/اندروید هنوز تأیید نشده‌اند.
- سرویس تولید و درگاه پرداخت همچنان به تنظیمات و دسترسی‌های واقعی نیاز دارند.


## نشان و کانال‌های خبرفوری

نشان و آیکن اصلی از سایت معرفی‌شده دریافت شده‌اند. ۱۲ نشانی شبکه اجتماعی از لینک‌های همان سایت برداشته شده و در صفحه «کانال‌های خبرفوری» قرار دارند. سورس تصویر و نشانی‌ها در `public/brand` و نسخه Flutter در `mobile/assets/brand` است. مستند منبع و هش فایل‌ها در `BRAND-SOURCES.md` ثبت شده است.

دسترسی به سایت `www.khabarfoori.com` به معنی در اختیار داشتن API یا پنل مدیریت آن نیست؛ این نشانی را به‌جای `API_URL` بک‌اند NestJS وارد نکنید.
