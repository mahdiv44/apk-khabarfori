# اتصال واقعی دیتابیس و استقرار

این نسخه PostgreSQL را در کانتینر خصوصی VPS اجرا می‌کند. API و پنل پورت عمومی ندارند؛ فقط Caddy روی 80 و 443 منتشر می‌شود. قبل از اجرا دامنه را به IP سرور متصل کنید.

```bash
cp deploy/vps/.env.vps.example .env.vps
nano .env.vps
bash deploy/vps/install.sh
```

مهاجرت Prisma قبل از اجرای API اجرا می‌شود. پس از بالا آمدن، `https://DOMAIN/api/v1/health` باید `status: ok` برگرداند. فایل `.env.vps` هرگز commit نشود. برای بکاپ از `pg_dump` استفاده کنید و بازیابی را دوره‌ای روی دیتابیس آزمایشی تمرین کنید.

ورود مدیر با ایمیل تنظیم‌شده انجام می‌شود. کاربران می‌توانند شماره با قالب `09…` یا `+98…` ثبت کنند؛ ورود پیامکی/OTP بدون اتصال سرویس SMS فعال نیست. حقوق فقط پس از unlock با رمز جداگانه و هش bcrypt دیده می‌شود و تلاش‌های ناموفق قفل موقت ایجاد می‌کنند.

اتصال مستقیم SSH این محیط به VPS قبلاً با `Network is unreachable` متوقف شده است؛ این فایل‌ها آماده اجرا هستند اما استقرار روی سرور تا اجرای فرمان توسط مالک سرور تأیید نشده است.
