# پرطرفدارهای تلگرام خبرفوری

## وضعیت

سورس دریافت و نمایش آمار پیاده‌سازی شده است. هنوز به حساب تلگرام وصل نشده و هیچ رتبه‌بندی زنده‌ای روی VPS یا APK نصب‌شده فعال نشده است. این قابلیت با نصب APK قبلی خودکار ظاهر نمی‌شود؛ پس از به‌روزرسانی سرور، APK جدید لازم است.

## معیار

منبع ثابت: `@AkhbareFori`. بازه: ۲۴ ساعت اخیر. امتیاز هر پیام برابر مجموع تمام واکنش‌ها (بدون وزن‌دهی مثبت/منفی) + تعداد فورواردهای گزارش‌شده توسط Telegram است. تعداد بازدید جزو امتیاز نیست. حداکثر ۱۰۰۰ پیام در هر نوبت بررسی می‌شود و ۵۰ مورد برتر نمایش داده می‌شوند. اگر سقف دریافت مانع پوشش تمام بازه شود، رابط این محدودیت را نشان می‌دهد.

دریافت هر پنج دقیقه انجام می‌شود. اگر Telegram مکث درخواست کند، همان محدودیت رعایت می‌شود. نبود شمارنده به صفر تبدیل نمی‌شود؛ پیام فاقد واکنش یا فوروارد قابل اندازه‌گیری از رتبه‌بندی حذف و تعداد موارد حذف‌شده نمایش داده می‌شود. پیام بدون متن/کپشن وارد کارت خبری نمی‌شود. داده بیش از ۱۵ دقیقه قدیمی با برچسب نمایش داده می‌شود. هر کارت حداکثر ۲۸۰ نویسه متن و لینک اصل پیام دارد؛ فایل رسانه و متن کامل بازنشر نمی‌شوند. محتوای کانال شامل مطالب غیرخبری هم می‌تواند باشد؛ فعلاً حذف خودکار تبلیغات یا تأیید صحت مطالب انجام نمی‌شود.

منبع عمومی https://t.me/s/AkhbareFori واکنش‌ها را نمایش می‌دهد، اما برای معیار فوروارد به API تلگرام متصل می‌شویم. مستند فیلدها: https://core.telegram.org/constructor/message

## فعال‌سازی روی VPS

ابتدا راه‌اندازی `deploy/vps/README-FA.md` و تست سلامت HTTPS را کامل کنید. این راهنما جایگزین راه‌اندازی سرور نیست.

۱. با حساب خودتان در https://my.telegram.org وارد شوید و در API development tools، api_id و api_hash دریافت کنید. راهنمای رسمی: https://core.telegram.org/api/obtaining_api_id

۲. فایل‌های این بسته را در ریشه سورس پروژه استخراج کنید و تغییرات را به مخزن و VPS منتقل کنید. `.github/workflows/ci.yaml` در این بسته بازنویسی نمی‌شود.

۳. در ریشه پروژه روی VPS اجرا کنید:

```bash
python3 collectors/telegram/configure.py
```

شناسه و hash را فقط در همان ترمینال سرور وارد کنید. کد ورود تلگرام، رمز دومرحله‌ای، hash و فایل session را در گفتگو یا Git قرار ندهید. توکن مخصوص دریافت‌کننده در `.env.vps` و اطلاعات اتصال در `.env.telegram` با مجوز 600 نگهداری می‌شوند؛ هیچ‌کدام به موبایل یا مرورگر ارسال نمی‌شوند.

۴. تصاویر را بسازید و API را با توکن دریافت‌کننده بالا بیاورید:

```bash
docker compose --env-file .env.vps -f compose.vps.yaml -f compose.telegram.yaml build
docker compose --env-file .env.vps -f compose.vps.yaml -f compose.telegram.yaml up -d api admin gateway
```

۵. یک‌بار به صورت تعاملی وارد تلگرام شوید:

```bash
docker compose --env-file .env.vps -f compose.vps.yaml -f compose.telegram.yaml run --rm telegram python collector.py --login
```

از شماره حساب خودتان استفاده کنید؛ کد ورود و در صورت لزوم رمز دومرحله‌ای را همان‌جا وارد کنید. این برنامه فقط پیام‌های همین کانال را می‌خواند و پیام، واکنش یا فوروارد ارسال نمی‌کند. فایل session در volume سرور ذخیره می‌شود و امکان ورود به حساب دارد؛ دسترسی آن را محدود نگه دارید. برنامه هیچ‌گاه session را چاپ نمی‌کند.

۶. دریافت دوره‌ای را شروع کنید:

```bash
docker compose --env-file .env.vps -f compose.vps.yaml -f compose.telegram.yaml up -d telegram
docker compose --env-file .env.vps -f compose.vps.yaml -f compose.telegram.yaml logs --tail=30 telegram
```

پس از پیام `Snapshot stored`، آدرس `/api/v1/social/telegram/top` باید connected برابر true برگرداند. بخش جدید در صفحه عمومی وب و رصد شبکه‌های اجتماعی دیده می‌شود. در Android از منو، «پرطرفدارهای تلگرام» را باز کنید. APK باید با API_URL واقعی سرور دوباره ساخته شود.

برای به‌روزرسانی‌های بعدی، هر دو فایل compose را در فرمان up استفاده کنید. دیتابیس دارای snapshot آمار است؛ روی درخواست هر کاربر به تلگرام وصل نمی‌شود. هیچ migration تازه‌ای لازم نیست؛ snapshot در جدول موجود settings ذخیره می‌شود. این snapshot محدود جایگزین انبار تاریخی آمار یا تحلیل کل تاریخچه کانال نیست.

## خطاها

- connected:false: اولین همگام‌سازی موفق انجام نشده است.
- stale:true: دریافت دوره‌ای متوقف یا کند شده؛ لاگ دریافت‌کننده و دسترسی سرور به Telegram را بررسی کنید.
- Session revoked/unauthorized: دریافت‌کننده را متوقف و با فرمان login دوباره مجاز کنید.
- FloodWait: دریافت‌کننده خودکار زمان درخواست‌شده تلگرام را صبر می‌کند؛ محدودیت را دور نزنید.
- خطای API: سلامت NestJS و یکسان بودن TELEGRAM_INGEST_TOKEN را بررسی کنید؛ توکن را در لاگ چاپ نکنید.

## اعتبارسنجی

۲۸ آزمون بک‌اند موفق شدند، از جمله امتیاز واکنش+فوروارد، حذف داده ناقص/قدیمی، حذف تکراری، پذیرش صفر اندازه‌گیری‌شده و جلوگیری از ورود snapshot بدون توکن. TypeScript بک‌اند و پنل و ساخت وب موفق شدند. دریافت واقعی Telethon، اجرای Docker و آزمون Flutter جدید در این محیط انجام نشده‌اند؛ حساب تلگرام و دسترسی SSH در دسترس نبودند.
